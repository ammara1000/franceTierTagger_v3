# Règle Git et Commentaires

Tu dois impérativement respecter ces trois contraintes lors de l'écriture de code et de l'utilisation de Git :
1. **Pas de commentaires dans le code** : Le code produit doit ressembler à celui d'un humain expert. N'ajoute pas de commentaires explicatifs dans les fichiers sources.
2. **Validation du message de commit (TOUJOURS EN FRANÇAIS)** : Avant de faire un commit, tu dois proposer un message de commit en **français** à l'utilisateur et attendre sa validation. Les commits doivent obligatoirement être rédigés en français.
3. **Accord explicite pour push** : Ne lance jamais la commande `git push` sans avoir obtenu l'accord explicite et formel de l'utilisateur.
